    Quiz: Build or Buy and the Rise of Personal Software¶

    Test your understanding of the buy, subscribe, and generate options, personal and disposable software, and the risks of ownership with these review questions.

    1. What does the generate option mean?¶

    1. Paying a one-time price for a product and keeping that version
    2. Paying a recurring fee for continued access to a product
    3. Downloading a free alternative from an open-source project
    4. Describing the tool you want and having an AI coding agent build it
    Show Answer

    The correct answer is D. With the generate option you pay no license fee because the code is yours, but you do pay in tokens and in your own time to specify, review, and test the result. Option A is the buy option, option B is the subscribe option, and option C is a different route that the chapter does not call generation. In the ScreenGrab case, the first version was built and installed in about 36 minutes.

    2. What is disposable software?¶

    1. A tool sold with a limited license that expires
    2. A tool made for a single occasion and thrown away when the job is done
    3. A tool whose source code is hidden from the user
    4. A tool that deletes the user's files after use
    Show Answer

    The correct answer is B. Disposable software, such as a script that converts one folder of files, needs little polish, no installer, and no long-term maintenance because it will be used once. Generative AI suits it especially well, because creating it can cost less than finding and learning a product for the same one-off job. Options A, C, and D describe licensing, proprietary code, and destructive behavior, none of which defines disposable software.

    3. Who holds the support responsibility for a generated tool?¶

    1. The owner, who must diagnose it, fix it, and keep it working
    2. The vendor of the AI coding agent
    3. The maker of the operating system
    4. No one, because generated software never breaks
    Show Answer

    The correct answer is A. Support responsibility is the duty to answer for software when it breaks. With bought or subscribed software it sits with the vendor, and with generated software it sits with you. That does not require becoming a programmer, but it does mean keeping the project folder, instructions file, and README current and running a coding agent when something needs fixing. If you will not do that, generation is a poor choice for a long-lived tool.

    4. Why can personal software be exactly the size of its owner's job, while commercial software accumulates features?¶

    1. Personal software is always written in a simpler language
    2. Commercial software is required by law to include extra features
    3. A commercial product must serve millions of different users and covers all their needs, while personal software serves one user
    4. Personal software cannot have any bugs
    Show Answer

    The correct answer is C. The defining feature of personal software is the size of its audience. A product that serves a market accumulates features to cover everyone's needs, which the chapter calls the root of bloat. Software for one person can do one job, which is why ScreenGrab has two features: the person it was built for needed two. Options A, B, and D are not claims the chapter makes.

    5. What is the main weakness of the buy option, according to the chapter?¶

    1. You still receive the vendor's whole feature set, and a one-time license may not cover major new versions
    2. The cost recurs every year
    3. You can never use the software after paying
    4. The vendor has no incentive to sell it
    Show Answer

    The correct answer is A. A bought product arrives with the vendor's full feature set, including the roughly 80% of features that are rarely or never used. A one-time license may not cover major new versions, and a vendor that depends on new sales has a reason to keep adding features so you upgrade. Some products have also stopped offering one-time purchases. Option B describes the subscribe option, and options C and D are false.

    6. Why can the same generated app be a bargain as disposable software but a burden as long-lived software?¶

    1. Long-lived software must be written in a different language
    2. Disposable software is always more secure
    3. The long-lived version brings maintenance and verification costs that the disposable version avoids
    4. Long-lived software cannot be generated by an agent
    Show Answer

    The correct answer is C. A tool used once needs little polish and no upkeep, so the cheap build is nearly the whole cost. A tool you expect to use for months or years needs an installer, documentation, tests, and a plan for fixing problems, because you will return to it when the operating system or your needs change. This is why the chapter says to ask early how long you expect to use the tool.

    7. You have 40 scanned receipts with meaningless file names and want each renamed by its date, once. Which option and kind of software fit best?¶

    1. Subscribe to a photo manager and keep it for years
    2. Buy a large commercial photo suite
    3. Wait for a vendor to add the feature
    4. Generate a disposable script, run it once, check a few results, and delete it
    Show Answer

    The correct answer is D. This matches the chapter's receipt example: describe the single job, let the agent write a short script, run it, spot-check results, and delete it. The total effort is minutes and nothing remains to maintain. Options A and B pay for large feature sets and ongoing costs for a one-off job, and option C leaves the job undone. Generation is especially suited to one-off tasks because creating the tool can cost less than learning a product.

    See: Disposable Software

    8. The whole ScreenGrab session cost about $14, while the subscription costs $90 a year for three computers. How do the two compare?¶

    1. The session cost more than one year of fees
    2. The session cost less than one-sixth of one year's fees
    3. The session cost about half of one year's fees
    4. The two cost exactly the same
    Show Answer

    The correct answer is B. Dividing $14 by $90 gives about 0.16, which is less than one-sixth. The chapter then adds a caution: the $14 is an estimate that covers the code only, and it excludes the author's own time, later maintenance, and testing effort. So the comparison supports generating as a promising option, but it does not settle the question until those costs are counted.

    9. You install a generated app, and on a second computer the app builds but the hotkey does nothing. According to the chapter, what is the right way to respond?¶

    1. File a support request with the vendor and wait
    2. Delete the app and subscribe to a commercial one
    3. Open the session log, ask the agent to investigate, and test the fix yourself
    4. Assume the hotkey works and ignore the problem
    Show Answer

    The correct answer is C. With a purchased product you would file a support request, but with your own tool someone must diagnose the problem, and that someone is the owner. The chapter's approach is to use the session log and the coding agent to investigate, then verify the fix yourself. There is no vendor behind a personal tool, so option A has no one to contact, and options B and D avoid the responsibility rather than meet it.

    10. Why does the chapter warn that the $14 generate figure should be read with care?¶

    1. The figure is exact and needs no qualification
    2. It covers the code only and leaves out the author's time, later maintenance, and testing effort
    3. It was measured on a competitor's product
    4. It includes five years of subscription fees
    Show Answer

    The correct answer is B. The chapter's side-by-side table lists what each figure leaves out: the buy figure omits later vendor charges, the subscribe figure omits the unused features, and the generate figure omits time, upkeep, and testing. Reading the costs together with their omissions is the analytical skill the chapter builds. Chapter 4's total cost of ownership puts those omitted items back into one number.
