# Appendices

These appendices hold reference material that supports the chapters but would interrupt them.

## Snagit Pricing

The first two appendices record what Snagit costs, which anchors the total cost of ownership comparison in the book.

- [Snagit Pricing, November 2026](snagit-pricing-2026-11.md) gives the current annual price, the computer limit, and the sources.
- [Snagit Price History, 2010–2026](snagit-prices-history.md) traces US single-user Mac prices year by year and separates perpetual purchases from subscriptions.

## Platform Risk

- [macOS API Disruption Risk](macos-api-disruption-risk.md) lists every Apple API that ScreenGrab calls and ranks them by how likely a future macOS release is to break or change them.
