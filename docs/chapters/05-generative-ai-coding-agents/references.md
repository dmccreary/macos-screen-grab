# References: Generative AI and Coding Agents

1. [Large language model](https://en.wikipedia.org/wiki/Large_language_model) - Wikipedia - Explains how language models are trained and used to generate text and code, including limits such as hallucination. Foundation for what a coding agent is built on.

2. [Generative artificial intelligence](https://en.wikipedia.org/wiki/Generative_artificial_intelligence) - Wikipedia - Surveys systems that generate text, code, and images from prompts, with history and risks. Places coding agents within the wider field this chapter introduces.

3. [Intelligent agent](https://en.wikipedia.org/wiki/Intelligent_agent) - Wikipedia - Defines an agent as an entity that perceives its environment and takes actions toward goals. Supplies the vocabulary behind the chapter's read-edit-run stages of a coding agent.

4. Artificial Intelligence: A Modern Approach - Stuart Russell and Peter Norvig - Pearson - Russell and Norvig organized the field around the rational agent: percepts, actions, environment, and performance measure. That unifying frame makes a coding agent's loop easy to describe precisely.

5. Co-Intelligence: Living and Working with AI - Ethan Mollick - Portfolio - Mollick popularized the jagged frontier, where AI excels at some tasks and fails unpredictably at others, and the practice of staying a human in the loop. Anchors the chapter's advice on oversight.

6. [Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents) - Anthropic - Distinguishes workflows from agents and describes patterns such as prompt chaining and tool use. Gives a practitioner's account of how coding agents are structured.

7. [Claude Code Overview](https://docs.claude.com/en/docs/claude-code/overview) - Anthropic Docs - Documents a terminal coding agent that reads files, runs commands, and edits code. A concrete example of the agent workflow described in the chapter.

8. [Claude Code: Best Practices for Agentic Coding](https://www.anthropic.com/engineering/claude-code-best-practices) - Anthropic - Shares tested habits for directing a coding agent: explore, plan, then implement, with checks along the way. Illustrates where a person must stay in the loop.

9. [Prompt Engineering Overview](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) - Anthropic Docs - Describes how to state goals, give context, and iterate on prompts. Shows how the quality of instructions shapes what a coding agent produces.

10. [Vibe coding](https://simonwillison.net/2025/Mar/19/vibe-coding/) - Simon Willison - Separates careless vibe coding from responsible AI-assisted programming where the developer reviews and understands the result. Useful for telling supported claims from overconfident ones.
