# Concept Taxonomy

Each concept in the learning graph belongs to one of these categories. The list runs from foundational ideas to the course capstone.

| Category | TaxonomyID | Concepts | What belongs here |
|---|---|---:|---|
| Software Bloat And Feature Usage | BLOAT | 30 | How products gain features, how those features are used, and what the excess costs users. |
| Licensing And Vendor Economics | LIC | 19 | License models, vendor revenue and incentives, switching costs, and lock-in. |
| Total Cost Of Ownership | TCO | 10 | The full cost of a tool over time and across several computers. |
| Build-Or-Buy Decisions | BUILD | 12 | Choosing between buying, subscribing to, and generating a tool, and what owning it involves. |
| Generative AI And Coding Agents | GENAI | 22 | What AI coding agents are, how to work with them, and how they can go wrong. |
| Requirements And Specifications | REQ | 12 | Stating what a tool must do and, just as importantly, what it must leave out. |
| Software Design | DESGN | 11 | Design decisions, trade-offs, prototypes, and platform constraints. |
| Code, Build, And Version Control | CODE | 16 | Source code, build and install scripts, signing, and Git. |
| ScreenGrab Case Study | CASE | 11 | The features and decisions specific to the ScreenGrab app. |
| Measuring AI Work | MEAS | 19 | Wall-clock time, token types, pricing, and estimating what a session costs. |
| Verification And Testing | TEST | 24 | Automated and manual testing, bug investigation, and honest reporting of results. |
| Maintenance And Open Source | OSS | 20 | Keeping a tool working, sharing it under an open source license, and the course capstone. |
